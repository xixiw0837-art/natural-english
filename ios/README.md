# LinguaKey — iOS keyboard prototype

This folder contains native Swift source for a **custom keyboard extension**, not an installable IPA.

## Build on Mac
1. Install Xcode. Create a new iOS App project named NaturalEnglish (Swift, SwiftUI).
2. Add a **Custom Keyboard Extension** target named NaturalEnglishKeyboard.
3. Replace the generated KeyboardViewController.swift with the file in NaturalEnglishKeyboard/.
4. Add PhraseTranslator.swift to the keyboard extension target (verify Target Membership).
5. Retain the extension Info.plist generated by Xcode, including com.apple.keyboard-service and its principal class. Keep RequestsOpenAccess = NO for the offline prototype.
6. Choose your Apple ID team under Signing & Capabilities for app and extension. Run on a connected iPhone.
7. On iPhone open Settings > General > Keyboard > Keyboards > Add New Keyboard.

## Current limitations
- Only the listed offline Chinese phrases translate. Arbitrary real-time translation and English-to-Chinese are not implemented.
- This is not a full Pinyin input method: its input area supports paste, but does not include Chinese character composition.
- Some apps and secure text fields do not allow third-party keyboards.
- Not yet compiled or tested on an actual device.
